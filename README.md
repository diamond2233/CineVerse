# 🎬 Magic Stream

A modern full-stack movie streaming platform built with **React**, **Golang**, **MongoDB**, and **OpenAI**. Users can browse movies, watch trailers, receive AI-powered movie recommendations, and securely manage their accounts through JWT authentication.

---

## 🚀 Features

- 🔐 Secure JWT Authentication
- 👤 User Registration & Login
- 🎥 Browse and Search Movies
- ▶️ Watch Movie Trailers
- 🤖 AI-Powered Movie Recommendations using OpenAI
- 🎬 Admin Movie Management
- 📱 Responsive User Interface
- ⚡ RESTful APIs with Golang
- 🗄️ MongoDB Database Integration

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/magic-stream.git
cd magic-stream
```

### Backend Setup

```bash
cd server
go mod tidy
go run main.go
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=8080
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
OPENAI_API_KEY=your_openai_api_key
```
